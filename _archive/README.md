# _archive/

Files moved here during the architectural refactor (2026-03-28).
Nothing here is loaded by the running application.
Keep for reference; delete when no longer needed.

## old_pipeline/
The original data orchestration pipeline, now superseded by the new
service/repository/integration architecture.

| File | Was used for |
|---|---|
| datahub.py | Precomputed fuzzy-matched artifacts (compiled_records.json, townland_index.json) |
| fuzzy.py | RapidFuzz greedy clustering for individual record linkage |
| preprocess.py | Cleaning raw Excel source into unified_processed.csv |
| family_graph.py | Graph construction for a D3.js visualisation that was never wired up |
| generate_precomputed.py | CLI trigger for DataHub.ensure_precomputed() |

Census and townland data is now served from the SQLite DB (coolattin.db at
project root) via census_service.py / townland_service.py.
